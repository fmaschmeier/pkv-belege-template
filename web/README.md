# Web-App

React-Oberfläche mit Übersicht, Belegen, Leistungsabrechnungen, Kontobewegungen, Abgleichsregeln
und Erinnerungen an die Versicherung nach § 14 VVG.

```bash
npm ci
npm run dev     # http://localhost:5173, Werte aus web/.env (Vorlage: .env.example)
npm run build   # Typprüfung und Produktions-Build
```

Einstellungen und Deployment: [`docs/EINRICHTUNG.md`](../docs/EINRICHTUNG.md#3-web-app-web-react).
